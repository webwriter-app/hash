Computers are able to check such lists automatically and thus test a large number of passwords in a short time. This approach is called a dictionary attack.

The length of the password hardly matters to the computer, as long as it is contained in the word list. There are huge lists of passwords on the internet that were captured in real data leaks. This is an important reason why you should never use the same password for different accounts.
