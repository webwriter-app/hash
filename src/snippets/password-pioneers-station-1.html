Hashing

Infodot was very excited: he was finally allowed to sign up on the platform “PrintMyBot” - a website where small robots and figures like himself can swap blueprints.

“Maybe I'll even find a new hairstyle to print out there!” he said happily. As he was thinking up a password, he asked curiously: “Is that simply stored somewhere now?”

At first he thought that the website would store his password exactly as he had entered it - as a word in plain text. That sounded logical. But he soon learned that this would be dangerous. If someone breaks into the website's computer system, that person could read all the passwords - exactly as they are!

That is why websites use a kind of “secret recipe”: so-called hash functions. This turns the password into a long string of characters that looks like a random mix of letters and numbers. From it, you can no longer trace back what the original password was. The next time you log in, the website simply checks whether the new string looks exactly like the stored one.

“That's like a secret fingerprint of my password!”, thought Infodot - and now he felt much safer.

Careful!
Hashing is a one-way street: it only works in one direction.

Now we want to start working hands-on.

Step by step, we will now look at different hashing methods, or algorithms and especially at their effects on input texts. To do this, we will work interactively with the Hashing Widget.

How to try out the widget

Input: As you can see, the widget contains a Key node (input), a Hash function node and a Hash value node (output). Watch how the output changes as soon as you enter some text.

Creating nodes: Choose a node from the list on the left, drag it into the editor while holding down the mouse button and drop it there. You can reposition the nodes at any time by clicking and moving them. Once you have added a node, you can select a hashing algorithm (for now, we will stick with SHA-256). If you want to rename a node, simply click on its title.

Deleting nodes: Click the trash can icon to remove a node and its connections.

Connecting nodes: For hashing to work, you need at least one hash function node as well as input and output nodes. Connect the dots of the nodes with each other (input - hash function - output). A hash function node can be connected to up to four input nodes.

Now that we can operate the widget, let's use it to get a feel for the three algorithms SHA256, SHA384 and SHA512.
